Czym jest pozycjonowanie?

Pozycjonowanie w CSS określa sposób rozmieszczania elementów na stronie internetowej. Dzięki niemu można kontrolować miejsce wyświetlania obiektów, tworzyć układy stron, menu, banery, okna dialogowe oraz wiele innych elementów interfejsu.

Pozycjonowanie realizowane jest głównie za pomocą właściwości position oraz dodatkowych właściwości takich jak: top, right, bottom i left.

Właściwość position

Właściwość position określa sposób pozycjonowania elementu. Najczęściej używane wartości to:

  • static
  • relative
  • absolute
  • fixed
  • sticky

Position: static

Static jest domyślną wartością dla wszystkich elementów HTML. Element znajduje się w normalnym przepływie dokumentu i nie reaguje na właściwości top, left, right oraz bottom.

div{ position: static; }

W większości przypadków nie trzeba ustawiać tej wartości ręcznie.

Position: relative

Relative pozwala przesuwać element względem jego normalnego położenia. Miejsce zajmowane przez element w dokumencie pozostaje zachowane.

div{ position: relative; top:20px; left:30px; }

Element zostanie przesunięty o 20 pikseli w dół i 30 pikseli w prawo.

Position: absolute

Absolute usuwa element z normalnego przepływu dokumentu. Pozycja jest ustalana względem najbliższego elementu nadrzędnego, który posiada pozycjonowanie relative, absolute lub fixed.

div{ position:absolute; top:50px; left:100px; }

Element może nachodzić na inne elementy znajdujące się na stronie.

Position: fixed

Fixed przykleja element do określonego miejsca okna przeglądarki. Po przewijaniu strony jego położenie nie zmienia się.

div{ position:fixed; top:0; right:0; }

Ten typ pozycjonowania często wykorzystywany jest w menu, przyciskach „Powrót do góry” oraz komunikatach.

Position: sticky

Sticky jest połączeniem relative i fixed. Element zachowuje się normalnie do momentu osiągnięcia określonej pozycji, a następnie przykleja się do ekranu.

div{ position:sticky; top:0; }

Sticky często stosowany jest w nagłówkach tabel oraz przyklejanych menu nawigacyjnych.

Właściwości top, right, bottom i left

Pozycjonowane elementy można przesuwać za pomocą dodatkowych właściwości.

Właściwość Działanie
top Przesunięcie od górnej krawędzi
right Przesunięcie od prawej krawędzi
bottom Przesunięcie od dolnej krawędzi
left Przesunięcie od lewej krawędzi

Z-index

Gdy elementy nachodzą na siebie, można określić który ma znajdować się na wierzchu. Służy do tego właściwość z-index.

div{ position:absolute; z-index:10; }

Im większa wartość z-index, tym wyżej znajduje się element.

Przykład pozycjonowania absolute względem relative

.container{ position:relative; width:400px; height:200px; } .box{ position:absolute; top:20px; left:30px; }

Element .box zostanie ustawiony względem kontenera .container.

Porównanie rodzajów pozycjonowania

Typ Opis
static Domyślne położenie elementu
relative Przesunięcie względem własnej pozycji
absolute Pozycjonowanie względem rodzica
fixed Stała pozycja na ekranie
sticky Przyklejanie podczas przewijania

Zastosowania pozycjonowania

  • Tworzenie menu nawigacyjnych.
  • Przyklejane nagłówki.
  • Banery reklamowe.
  • Okna dialogowe.
  • Galerie zdjęć.
  • Przyciski „Powrót do góry”.
  • Układy stron internetowych.

Podsumowanie

  • Pozycjonowanie określa położenie elementów na stronie.
  • Najważniejsza właściwość to position.
  • Static jest wartością domyślną.
  • Relative przesuwa element względem jego pozycji.
  • Absolute pozycjonuje względem rodzica.
  • Fixed przykleja element do okna przeglądarki.
  • Sticky łączy cechy relative i fixed.
  • Z-index określa kolejność wyświetlania elementów.
