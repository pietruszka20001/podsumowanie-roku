Czym jest menu rozwijane?

Menu rozwijane (Dropdown Menu) to element interfejsu użytkownika, który pozwala ukryć dodatkowe opcje nawigacyjne i wyświetlać je dopiero po wykonaniu określonej akcji. Najczęściej opcje pojawiają się po najechaniu kursorem myszy lub kliknięciu.

Dzięki temu można zmniejszyć ilość miejsca zajmowanego przez menu oraz uporządkować większą liczbę odnośników.

Zastosowanie menu rozwijanego

  • Nawigacja stron internetowych.
  • Panele administracyjne.
  • Sklepy internetowe.
  • Wielopoziomowe kategorie.
  • Menu użytkownika po zalogowaniu.

Podstawowa struktura HTML

Menu rozwijane składa się zwykle z przycisku lub odnośnika oraz ukrytej listy elementów.

HTML CSS JavaScript

Ukrywanie elementów

Domyślnie rozwijana część menu jest ukryta za pomocą właściwości display:none.

.dropdown-content{ display:none; }

Dzięki temu użytkownik widzi jedynie główny przycisk menu.

Pseudoklasa :hover

Pseudoklasa :hover aktywuje styl po najechaniu kursorem myszy na element. Jest najczęściej wykorzystywana do obsługi prostych menu rozwijanych.

.dropdown:hover .dropdown-content{ display:block; }

Po najechaniu na element dropdown ukryte opcje zostaną wyświetlone.

Pełny przykład CSS

.dropdown{ position:relative; display:inline-block; } .dropdown-content{ display:none; position:absolute; background:white; min-width:200px; } .dropdown:hover .dropdown-content{ display:block; }

Dlaczego używa się position:absolute?

Rozwijana część menu najczęściej posiada pozycjonowanie absolute. Pozwala to wyświetlić listę opcji pod przyciskiem bez przesuwania pozostałych elementów strony.

.dropdown-content{ position:absolute; }

Position: relative w kontenerze

Element nadrzędny często otrzymuje position:relative. Dzięki temu rozwijane menu jest pozycjonowane względem swojego kontenera.

.dropdown{ position:relative; }

Stylowanie odnośników

Elementy menu można dowolnie stylować za pomocą CSS.

.dropdown-content a{ display:block; padding:10px; text-decoration:none; }

Każdy odnośnik będzie wyświetlany w osobnym wierszu.

Efekt podświetlenia

Po najechaniu na opcję można zmienić jej kolor tła.

.dropdown-content a:hover{ background-color:lightgray; }

Zalety menu rozwijanego

  • Oszczędność miejsca.
  • Lepsza organizacja nawigacji.
  • Łatwiejsze zarządzanie dużą liczbą linków.
  • Czytelniejszy interfejs użytkownika.
  • Możliwość tworzenia wielopoziomowych menu.

Wady menu rozwijanego

  • Zbyt rozbudowane menu może być nieczytelne.
  • Na urządzeniach mobilnych wymaga dodatkowych rozwiązań.
  • Niewłaściwe wykonanie może utrudniać dostępność strony.

Podsumowanie

  • Menu rozwijane pozwala ukrywać dodatkowe opcje.
  • Najczęściej wykorzystuje HTML oraz CSS.
  • Elementy są zwykle ukrywane za pomocą display:none.
  • Pseudoklasa :hover umożliwia ich wyświetlanie.
  • Position:absolute pozwala umieszczać menu nad innymi elementami.
  • Menu może posiadać wiele poziomów.
  • Jest często wykorzystywane w nowoczesnych witrynach internetowych.
