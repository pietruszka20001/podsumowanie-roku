Czym jest model pudełkowy?

Model pudełkowy (Box Model) opisuje sposób, w jaki przeglądarka wyświetla i oblicza rozmiary elementów na stronie internetowej. Każdy element HTML jest traktowany jak prostokątne pudełko składające się z kilku warstw.

Budowa modelu pudełkowego


+-----------------------+
|       MARGIN          |
|  +-----------------+  |
|  |     BORDER      |  |
|  | +-------------+ |  |
|  | |   PADDING   | |  |
|  | | +---------+ | |  |
|  | | |CONTENT  | | |  |
|  | | +---------+ | |  |
|  | +-------------+ |  |
|  +-----------------+  |
+-----------------------+

Każdy element składa się z:

  • Content – właściwa zawartość elementu.
  • Padding – odstęp między zawartością a obramowaniem.
  • Border – obramowanie elementu.
  • Margin – zewnętrzny odstęp od innych elementów.

Content

Content to obszar zawierający tekst, obraz lub inne elementy znajdujące się wewnątrz znacznika. Jego rozmiar można określać za pomocą właściwości width i height.

div{ width:300px; height:150px; }

Padding

Padding określa odstęp pomiędzy zawartością elementu a jego obramowaniem. Powoduje zwiększenie przestrzeni wewnątrz elementu.

div{ padding:20px; }

Można również ustawiać padding dla poszczególnych stron:

padding-top:20px; padding-right:20px; padding-bottom:20px; padding-left:20px;

Border

Border tworzy obramowanie wokół elementu. Można określić jego grubość, styl oraz kolor.

div{ border:3px solid black; }
Styl Opis
solid Linia ciągła
dashed Linia kreskowana
dotted Linia kropkowana
double Linia podwójna

Margin

Margin określa zewnętrzny odstęp pomiędzy elementami. Nie wpływa na zawartość elementu.

div{ margin:30px; }

Możliwe jest również ustawianie marginesów dla poszczególnych stron:

margin-top:20px; margin-right:20px; margin-bottom:20px; margin-left:20px;

Przykład modelu pudełkowego

div{ width:300px; padding:20px; border:2px solid blue; margin:30px; }

Szerokość całkowita elementu będzie większa niż 300px, ponieważ zostaną doliczone paddingi i obramowanie.

Box-sizing

Domyślnie przeglądarka dodaje padding i border do szerokości elementu. Właściwość box-sizing pozwala zmienić ten sposób obliczania rozmiaru.

box-sizing:border-box;

Dzięki temu szerokość elementu uwzględnia padding oraz border. Jest to najczęściej stosowane rozwiązanie w nowoczesnych projektach.

Przykład praktyczny

.box{ width:250px; padding:20px; border:3px solid red; margin:20px; background-color:lightgray; }

Powyższy kod tworzy element o szerokości 250 pikseli, z szarym tłem, czerwonym obramowaniem i odstępami.

Znaczenie modelu pudełkowego

Znajomość modelu pudełkowego jest bardzo ważna podczas projektowania układu strony. Pozwala poprawnie rozmieszczać elementy, kontrolować odstępy oraz unikać problemów z szerokością i wysokością obiektów.

Podsumowanie

  • Każdy element HTML jest traktowany jak pudełko.
  • Model pudełkowy składa się z Content, Padding, Border i Margin.
  • Padding tworzy odstęp wewnątrz elementu.
  • Border odpowiada za obramowanie.
  • Margin tworzy odstęp na zewnątrz elementu.
  • Box-sizing pozwala kontrolować sposób obliczania rozmiarów elementów.
