Czym są formularze?

Formularze HTML służą do wprowadzania i przesyłania danych przez użytkownika. Wykorzystywane są między innymi podczas logowania, rejestracji, wysyłania wiadomości, składania zamówień czy wyszukiwania informacji.

Podstawowym znacznikiem formularza jest element FORM. W jego wnętrzu umieszcza się pola do wprowadzania danych oraz przyciski.

Znacznik FORM

Element FORM tworzy formularz i określa sposób przesyłania danych. Najczęściej wykorzystuje atrybuty action oraz method.

  • action – adres, do którego zostaną wysłane dane.
  • method – sposób przesyłania danych.

Metody GET i POST

Atrybut method określa sposób przesyłania danych formularza.

Metoda Opis
GET Dane są widoczne w adresie URL.
POST Dane przesyłane są w treści żądania.

Znacznik INPUT

INPUT jest najczęściej używanym elementem formularzy. Pozwala użytkownikowi wprowadzać różnego rodzaju dane.

Rodzaj pola określany jest przez atrybut type.

Najpopularniejsze typy INPUT

Typ Zastosowanie
text Zwykły tekst
password Hasło
email Adres e-mail
number Liczby
date Data
tel Numer telefonu
file Wybór pliku
checkbox Pole wyboru
radio Przycisk opcji
range Suwak
color Wybór koloru
submit Wysłanie formularza
reset Wyczyszczenie formularza

Przykłady pól INPUT

Checkbox i Radio

Checkbox pozwala zaznaczyć wiele opcji jednocześnie, natomiast radio umożliwia wybór tylko jednej opcji z grupy.

Przycisk BUTTON

BUTTON tworzy przycisk wykonywający określoną akcję.

Może służyć do wysyłania formularza lub wykonywania skryptów JavaScript.

SELECT i OPTION

SELECT tworzy listę rozwijaną. Poszczególne pozycje definiowane są za pomocą OPTION.

TEXTAREA

TEXTAREA umożliwia wpisywanie większej ilości tekstu, np. treści wiadomości lub komentarza.

FIELDSET i LEGEND

FIELDSET służy do grupowania pól formularza, natomiast LEGEND nadaje nazwę grupie.

Dane osobowe

Walidacja formularzy

HTML pozwala automatycznie sprawdzać poprawność danych. Służą do tego odpowiednie atrybuty.

Atrybut Działanie
required Pole obowiązkowe
minlength Minimalna liczba znaków
maxlength Maksymalna liczba znaków
min Minimalna wartość
max Maksymalna wartość
pattern Wyrażenie regularne

Przykład kompletnego formularza

Podsumowanie

  • FORM służy do tworzenia formularzy.
  • INPUT umożliwia wprowadzanie danych.
  • Typ pola określa atrybut type.
  • GET i POST określają sposób przesyłania danych.
  • SELECT tworzy listę rozwijaną.
  • TEXTAREA służy do wpisywania dłuższego tekstu.
  • FIELDSET grupuje pola formularza.
  • LEGEND nadaje nazwę grupie pól.
  • Walidacja pozwala sprawdzać poprawność danych.
