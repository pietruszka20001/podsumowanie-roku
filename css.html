Czym są arkusze stylów CSS?

CSS (Cascading Style Sheets), czyli kaskadowe arkusze stylów, to język służący do opisywania wyglądu elementów strony internetowej. HTML odpowiada za strukturę strony, natomiast CSS odpowiada za jej wygląd.

Za pomocą CSS można zmieniać kolory, czcionki, rozmiary, odstępy między elementami, położenie obiektów oraz tworzyć animacje.

Jak działa CSS?

CSS składa się z selektora oraz deklaracji stylów. Selektor wskazuje element, który ma zostać ostylowany, natomiast deklaracje określają jego wygląd.

p { color: blue; font-size: 20px; }

W powyższym przykładzie wszystkie akapity będą wyświetlane kolorem niebieskim i rozmiarem czcionki 20 pikseli.

Schemat działania HTML i CSS

Tworzenie strony internetowej opiera się na współpracy HTML i CSS:

  1. HTML tworzy strukturę strony.
  2. CSS nadaje jej wygląd.
  3. Przeglądarka łączy oba pliki.
  4. Użytkownik widzi gotową stronę.

Rodzaje arkuszy stylów CSS

Istnieją trzy sposoby dodawania stylów CSS do strony internetowej.

1. Styl lokalny (Inline CSS)

Styl lokalny zapisuje się bezpośrednio w znaczniku HTML za pomocą atrybutu style.

<p style="color:red;"> Przykładowy tekst </p>

Zalety:

  • Szybkie zastosowanie pojedynczego stylu.

Wady:

  • Trudniejsza edycja większych projektów.
  • Powielanie kodu.

2. Styl wewnętrzny (Internal CSS)

Styl zapisuje się w sekcji head dokumentu wewnątrz znacznika style.

<head> <style> p{ color:red; } </style> </head>

Zalety:

  • Wszystkie style znajdują się w jednym miejscu.

Wady:

  • Działa tylko dla jednej strony.

3. Styl zewnętrzny (External CSS)

Najczęściej stosowany sposób. Style znajdują się w osobnym pliku .css.

<link rel="stylesheet" href="style.css">

Przykład pliku CSS:

body{ background-color: lightgray; } h1{ color: navy; }

Zalety:

  • Jeden plik obsługuje całą witrynę.
  • Łatwiejsza aktualizacja.
  • Mniejsza ilość kodu HTML.

Selektory CSS

Selektory określają, które elementy mają zostać ostylowane.

Selektor Przykład Działanie
Elementu p Wybiera wszystkie akapity.
Klasy .menu Wybiera elementy z klasą menu.
Identyfikatora #logo Wybiera element o danym id.
Uniwersalny * Wybiera wszystkie elementy.

Klasy i identyfikatory

Klasy można przypisywać wielu elementom. Identyfikator powinien występować tylko raz na stronie.

<p class="opis"> Tekst </p> <h1 id="naglowek"> Tytuł </h1> .opis{ color:green; } #naglowek{ color:blue; }

Dziedziczenie stylów

Niektóre właściwości CSS są dziedziczone przez elementy potomne. Przykładem jest kolor tekstu lub rodzaj czcionki.

body{ color:black; font-family:Arial; }

Wszystkie elementy wewnątrz body odziedziczą te ustawienia.

Podsumowanie

  • CSS odpowiada za wygląd strony internetowej.
  • HTML tworzy strukturę strony.
  • Istnieją trzy rodzaje arkuszy stylów: lokalne, wewnętrzne i zewnętrzne.
  • Najczęściej stosuje się zewnętrzne arkusze stylów.
  • CSS wykorzystuje selektory do wybierania elementów.
  • Klasy oznacza się kropką, a identyfikatory znakiem #.
