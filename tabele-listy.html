Listy w HTML

Listy służą do prezentowania informacji w uporządkowanej lub nieuporządkowanej formie. HTML udostępnia trzy podstawowe rodzaje list:

  • Lista nieuporządkowana (ul)
  • Lista uporządkowana (ol)
  • Lista definicji (dl)

Lista nieuporządkowana - ul

Lista nieuporządkowana wyświetla elementy oznaczone punktami.

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>

Efekt:

  • HTML
  • CSS
  • JavaScript

Lista uporządkowana - ol

Lista uporządkowana numeruje kolejne elementy.

<ol> <li>Uruchom komputer</li> <li>Otwórz przeglądarkę</li> <li>Wejdź na stronę</li> </ol>

Efekt:

  1. Uruchom komputer
  2. Otwórz przeglądarkę
  3. Wejdź na stronę

Znacznik li

Znacznik li (list item) oznacza pojedynczy element listy. Może być używany zarówno w listach uporządkowanych jak i nieuporządkowanych.

<li>Przykładowy element listy</li>

Lista definicji

Lista definicji służy do przedstawiania pojęć oraz ich opisów.

Znacznik Zastosowanie
<dl> Lista definicji
<dt> Nazwa pojęcia
<dd> Opis pojęcia
<dl> <dt>HTML</dt> <dd>Język znaczników</dd> <dt>CSS</dt> <dd>Arkusze stylów</dd> </dl>

Efekt:

HTML
Język znaczników służący do tworzenia stron internetowych.
CSS
Język odpowiedzialny za wygląd strony.

Tabele w HTML

Tabela umożliwia przedstawienie danych w wierszach i kolumnach.

Znacznik Opis
<table> Tworzy tabelę
<tr> Tworzy wiersz tabeli
<td> Tworzy komórkę tabeli
<th> Tworzy komórkę nagłówkową
<caption> Tytuł tabeli

Przykład tabeli

<table> <caption>Oceny ucznia</caption> <tr> <th>Przedmiot</th> <th>Ocena</th> </tr> <tr> <td>Informatyka</td> <td>5</td> </tr> <tr> <td>Matematyka</td> <td>4</td> </tr> </table>

Efekt:

Oceny ucznia
Przedmiot Ocena
Informatyka 5
Matematyka 4

Łączenie komórek tabeli

Do łączenia komórek używa się atrybutów colspan oraz rowspan.

Atrybut Działanie
colspan Łączy kolumny
rowspan Łączy wiersze
<td colspan="2">Połączone kolumny</td>

Podsumowanie

  • ul tworzy listę nieuporządkowaną.
  • ol tworzy listę uporządkowaną.
  • li oznacza pojedynczy element listy.
  • dl, dt i dd tworzą listę definicji.
  • table tworzy tabelę.
  • tr odpowiada za wiersz tabeli.
  • td tworzy komórkę z danymi.
  • th tworzy nagłówek tabeli.
  • caption dodaje tytuł tabeli.
