Witamy w samouczku przygotowanym jako powtórka do egzaminu zawodowego INF.03. Witryna zawiera najważniejsze informacje dotyczące tworzenia stron internetowych za pomocą języka HTML oraz arkuszy stylów CSS.

Czym jest HTML?

HTML (HyperText Markup Language) jest językiem znaczników służącym do tworzenia stron internetowych. Za pomocą odpowiednich znaczników opisuje strukturę dokumentu, który następnie jest interpretowany przez przeglądarkę internetową.

HTML pozwala tworzyć:

  • Nagłówki
  • Akapity tekstu
  • Listy
  • Tabele
  • Formularze
  • Odnośniki
  • Obrazy i multimedia

Do czego służy HTML?

HTML odpowiada za budowę i strukturę strony internetowej. Określa rozmieszczenie elementów takich jak tekst, obrazy, formularze czy tabele. Nie odpowiada jednak za wygląd strony – do tego wykorzystuje się język CSS.

W praktyce:

  • HTML tworzy strukturę strony.
  • CSS odpowiada za wygląd strony.
  • JavaScript dodaje funkcjonalność i interakcje.

Jak działa strona internetowa?

Proces wyświetlania strony internetowej przebiega w kilku etapach:

  1. Użytkownik wpisuje adres strony.
  2. Przeglądarka pobiera plik HTML z serwera.
  3. Przeglądarka analizuje znaczniki HTML.
  4. Ładowane są arkusze CSS.
  5. Strona zostaje wyświetlona użytkownikowi.
